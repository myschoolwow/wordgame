# MySchool WOW 3 — Ada V12

## GitHub Pages
1. Bu klasörün **içeriğini** deponun kök dizinine yükleyin (`index.html` kökte olmalı).
2. GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. Yayın bağlantısı `https://KULLANICI.github.io/DEPO/` biçiminde olur.
