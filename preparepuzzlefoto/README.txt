24 Isparta fotoğrafını Wikimedia Commons üzerinden otomatik indirir, 1500x1000 WebP'ye dönüştürür ve tema1..tema6/hafta1..hafta4 dizinine yerleştirir.
GitHub: Dosyaları depoya yükleyin -> Actions -> Isparta 24 puzzle fotografini hazirla -> Run workflow -> Artifacts bölümünden ZIP'i indirin.
Yerel: pip install Pillow ; python indir_ve_hazirla.py
ÖNEMLİ: Fotoğraflar bu pakette henüz yoktur. Çalıştırma internet gerektirir. Commons dosya lisanslarını FOTOGRAF_KAYNAKLARI.csv'den kontrol edin; atıf yükümlülükleri olabilir. Kaynaklarda bulunan 24 gerçek dosya adı kullanılmıştır, ancak bağlantılar ve lisanslar çalıştırılmadan doğrulanamamıştır.
